# Core Rebrand & Migration

- `src/identity.ts` is the single source for `APP_NAME=novacode`, `LEGACY_APP_NAME=opencode`, `CONFIG_DIR_NAMES`, `PROJECT_CONFIG_FILES`, `novaKey`/`appEnv`/`appEnvTruthy`/`isAppConfigDir`. Never read `OPENCODE_*` env directly; use `appEnv` so `NOVACODE_*` takes precedence.
- `src/flag/flag.ts` delegates all `OPENCODE_*` keys through `appEnv`/`appEnvTruthy` and `configBool(novaKey(...))`. `truthy()` auto-fallbacks for `OPENCODE_` prefix; `enabledByExperimental` checks explicit key first, then `OPENCODE_EXPERIMENTAL` fallback via `appEnvTruthy`.
- `src/global.ts:1` executes `migrateLegacyAppDirs` at module-load (before XDG paths). It copies `~/.opencode`→`~/.novacode` only when target is fresh, renames data files `opencode.*`→`novacode.*` (skips `.json`/`.jsonc`), and always `copyMissingLegacyDatabases` for `.db` files >8192 bytes. Guarded by `shouldMigrateLegacyApp` — tests must set `NOVACODE_DB=:memory:` or `NOVACODE_TEST_HOME` or `NOVACODE_SKIP_LEGACY_MIGRATE=true`.
- `src/global-migrate.ts:copyMissingLegacyDatabases` skips copying if dest `.db` already exists and is non-trivial; handles locked DB via try/catch. `isFreshDir` returns true on missing dir, so empty/missing target triggers full copy.
- `src/util/path.ts:rewritePathPrefix` is the canonical worktree/session path rewriter: normalizes `\`→`/`, strips trailing `/`, preserves `to` slash style, and only rewrites when `value` equals `from` or is under `from/`. Use it for any project/sandbox/session directory relocation (see `packages/opencode/src/project/project.ts:remapWorktree`).
